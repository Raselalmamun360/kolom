# উদাহরণ (Examples)

নয়টি ছোট, স্বয়ংসম্পূর্ণ প্রোগ্রাম — প্রতিটি ভাষার একটি নির্দিষ্ট অংশ দেখায়, এবং প্রতিটি ইন্টারপ্রেটেড ও নেটিভ — দুই মোডেই পরীক্ষিত।

| # | প্রোগ্রাম | দেখায় |
|---|-----------|-------|
| ০১ | [`হ্যালো`](01_হ্যালো/main.ক) | ভ্যারিয়েবল, বেসিক টাইপ, `লেখো` |
| ০২ | [`ক্যালকুলেটর`](02_ক্যালকুলেটর/main.ক) | ফাংশন, `যদি`/`নাহলে`, `যতক্ষণ` |
| ০৩ | [`কেনাকাটার_তালিকা`](03_কেনাকাটার_তালিকা/main.ক) | `ম্যাপ`, `প্রতি` (for-each) |
| ০৪ | [`ছাত্র_প্রোফাইল`](04_ছাত্র_প্রোফাইল/main.ক) | `তথ্য` (structs), নেস্টেড স্ট্রাক্ট |
| ০৫ | [`নোট_রাখা`](05_নোট_রাখা/main.ক) | ফাইল I/O, `চেষ্টা`/`ধরো` |

## চালানো

```console
kolom চালাও examples/01_হ্যালো/main.ক
```

সাতটি কনসোল প্রোগ্রাম (০১–০৬, ০৯) — `চালাও` (ইন্টারপ্রেটেড) দিয়েই সম্পূর্ণ কাজ করে। মাঝের দুটি (`গণক_অ্যাপ`, `ক্যানভাস_আর্ট`) নেটিভ UI ব্যবহার করে, যা **শুধু `কলম বিল্ড` দিয়ে বানানো এক্সিকিউটেবলেই** আসল উইন্ডো খোলে — `চালাও` ডিসপ্লে ব্লক নীরবে বাদ দেয় (ইন্টারপ্রেটার এখনো UI চালায় না)।

```console
kolom বিল্ড examples/07_গণক_অ্যাপ/main.ক
./গণক.exe
```

`গ্রেড_বিশ্লেষক` (০৯) ঐচ্ছিকভাবে একটি কমান্ড-লাইন আর্গুমেন্ট নেয় — একটি কাস্টম উত্তীর্ণের সীমা:

```console
kolom চালাও examples/09_গ্রেড_বিশ্লেষক/main.ক 70
```

## যাচাই

`crates/kolom-cli/tests/examples.rs` প্রতিটি কনসোল উদাহরণ ইন্টারপ্রেটেড ও নেটিভ — দুই মোডেই সফলভাবে চালিয়ে যাচাই করে, আর UI উদাহরণ দুটিকে পার্স ও টাইপ-চেক করে (`docs_examples.rs`-এর মতোই) — যাতে এই উদাহরণগুলো ভাষার বাকি অংশের সাথে সাথেই আপডেট থাকে, ডকুমেন্টেশনের মতো নিজে থেকে পুরনো হয়ে না যায়।
