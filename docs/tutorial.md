# কলম প্রোগ্রামিং ভাষা — সম্পূর্ণ টিউটোরিয়াল

**কলম** একটি বাংলা প্রোগ্রামিং ভাষা। এই ডকুমেন্টে ধাপে ধাপে শেখানো হবে কীভাবে কলম দিয়ে প্রোগ্রাম লিখতে হয়।

---

## ১. ইনস্টলেশন

কলম চালাতে আপনার লাগবে:
- **Rust** (compiler তৈরির জন্য): [rustup.rs](https://rustup.rs) থেকে
- **GCC/MinGW** (native exe তৈরির জন্য): Windows-এ [WinLibs](https://winlibs.com)

```bash
# কলম বিল্ড করুন
cd kolom
cargo build --release

# binary পাবেন: target/release/kolom.exe
```

## ৬. লুপ

### for loop (নির্দিষ্ট সংখ্যক বার)
```kolom
লুপ(৫) {
    লেখো("হ্যালো")
}
// ৫ বার প্রিন্ট হবে
```

### while loop
```kolom
ধরি i = ০
যতক্ষণ (i < ৫) {
    লেখো(লেখায়(i))
    i += ১
}
// 0, 1, 2, 3, 4
```

### for-each loop (অ্যারের উপর)
```kolom
ধরি ফলসমূহ = ["আম", "জাম", "কলা"]

প্রতি (ফল : ফলসমূহ) {
    লেখো(ফল)
}
// আম, জাম, কলা
```

### break ও continue
```kolom
লুপ(১০) {
    যদি (i == ৩) {
        continue        // skip this iteration
    }
    যদি (i == ৭) {
        break           // exit loop
    }
    লেখো(লেখায়(i))
}
```

### ঘোষণা ও ব্যবহার
```kolom
ফাংশন যোগ(সংখ্যা a, সংখ্যা b) -> সংখ্যা {
    রিটার্ন a + b
}

ফাংশন শুভেচ্ছা(লেখা নাম) -> লেখা {

}
```

### void function (কিছু ফেরত দেয় না)
```kolom
ফাংশন প্রিন্ট_লাইন() -> ফাঁকা {

}
```

### Recursion
```kolom
ফাংশন ফ্যাক্টরিয়াল(n: সংখ্যা) -> সংখ্যা {
    যদি (n <= ১) {
        রিটার্ন ১
    }
    রিটার্ন n * ফ্যাক্টরিয়াল(n - ১)
}

// ফ্যাক্টরিয়াল(৫) = 120
```

## ১২. ফাইল I/O

```kolom
ইম্পোর্ট ফাইল
ইম্পোর্ট ফাইলসিস্টেম

অ্যাপ {
    // ফাইলে লেখা
    ফাইল.লেখো("output.txt", "হ্যালো বাংলা!")

    // ফাইল আছে কি না
    যদি (ফাইলসিস্টেম.ফাইল_আছে("output.txt")) {
        লেখো("ফাইল আছে!")
    }

    // ডিরেক্টরি operations
    ফাইলসিস্টেম.ডিরেক্টরি_বানাও("new_folder")
    ধরি files = ফাইলসিস্টেম.তালিকা(".")
    প্রতি (f : files) {
        লেখো(f)
    }
}
```

## ১৩. লেখা Operations

```kolom
ইম্পোর্ট লেখা

অ্যাপ {
    ধরি s = "  হ্যালো বিশ্ব  "

    // Trim
    ধরি clean = লেখা.ছাঁটো(s)          // "হ্যালো বিশ্ব"

    // Uppercase/Lowercase (English only)
    লেখো(লেখা.বড়হাতের("hello"))        // HELLO
    লেখো(লেখা.ছোটহাতের("WORLD"))        // world

    // Split & Join
    ধরি parts = লেখা.স্প্লিট("a,b,c", ",")    // ["a", "b", "c"]
    ধরি joined = লেখা.জুড়াও(parts, "-")     // "a-b-c"

    // Replace
    ধরি fixed = লেখা.বদলাও("আম ভালো", "আম", "জাম")   // "জাম ভালো"

    // Find
    ধরি pos = লেখা.খুঁজো("হ্যালো", "ল")    // index of "ল"

    // Substring
    ধরি sub = লেখা.স্লাইস("বাংলাদেশ", ০, ৪)  // "বাংলা"

    // Starts/Ends with
    লেখো(লেখায়(লেখা.শুরুতে_আছে("বাংলা", "বাং")))   // true
}
```

## ১৬. নেটওয়ার্ক (TCP Client)

```kolom
ইম্পোর্ট নেটওয়ার্ক

অ্যাপ {
    // Connect to server
    ধরি sock = নেটওয়ার্ক.কানেক্ট("example.com", 80)

    // Send data
    নেটওয়ার্ক.সেন্ড(sock, "GET / HTTP/1.0\r\n\r\n")

    // Receive response (max 4096 bytes)
    ধরি response = নেটওয়ার্ক.রিসিভ(sock, 4096)
    লেখো(response)

    // Close connection
    নেটওয়ার্ক.ক্লোজ(sock)
}
```

## ২১. Complete Example — Student Grade Calculator

```kolom
ইম্পোর্ট লেখা

তথ্য ছাত্র {
    নাম: লেখা,
    নম্বর: সংখ্যা,
    গ্রেড: লেখা
}

ফাংশন গ্রেড_বের_করো(সংখ্যা marks) -> লেখা {
    যদি (marks >= ৮০) { রিটার্ন "A+" }
    যদি (marks >= ৭০) { রিটার্ন "A" }
    যদি (marks >= ৬০) { রিটার্ন "B" }
    যদি (marks >= ৫০) { রিটার্ন "C" }
    রিটার্ন "F"
}

অ্যাপ {
    ধরি ছাত্ররা: ম্যাপ[লেখা, সংখ্যা] = ম্যাপ_তৈরি()

    ছাত্ররা["রহিম"] = ৮৫
    ছাত্ররা["করিম"] = ৭২
    ছাত্ররা["সেলিনা"] = ৯১

    ধরি keys = চাবি_গুলো(ছাত্ররা)

    লেখো("=== ফলাফল ===")
    প্রতি (name : keys) {
        ধরি marks = ছাত্ররা[name]
        ধরি grade = গ্রেড_বের_করো(marks)
        লেখো(name + ": " + লেখায়(marks) + " → " + grade)
    }
```
