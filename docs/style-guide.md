# কলম বানান নির্দেশিকা (Style Guide)

এই ডকুমেন্ট ইংরেজি শব্দগুলোর জন্য **কলম**-এ ব্যবহৃত সরকারি বাংলা বানান নির্ধারণ করে, যাতে কোডবেজ ও সকল ডকুমেন্টেশনে বানানের ধারাবাহিকতা বজায় থাকে। নতুন কোনো কারিগরি শব্দ যোগ করার সময় এই তালিকা অনুসরণ করা উচিত।

| ইংরেজি   | কলম-এর সরকারি বানান                                       |
| -------- | ---------------------------------------------------------- |
| App      | অ্যাপ                                                       |
| Function | ফাংশন                                                       |
| Import   | ইম্পোর্ট                                                    |
| Compiler | কম্পাইলার                                                   |
| Compile  | কম্পাইল                                                     |
| Package  | প্যাকেজ                                                     |
| Module   | মডিউল                                                       |
| Display  | ডিসপ্লে                                                     |
| Text     | টেক্সট                                                      |
| Button   | বাটন                                                        |
| Input    | ইনপুট                                                       |
| JSON     | জেসন (`জেসন` স্ট্যান্ডার্ড লাইব্রেরি মডিউলের নাম)           |
| CLI      | CLI                                                         |
| Copy     | কপি                                                          |
| Memory   | মেমরি                                                        |
| Ownership | ওনারশিপ                                                     |
| Move     | মুভ                                                          |
| Reference-counted | রেফারেন্স-কাউন্টেড                                 |
| Widget | উইজেট                                                       |
| State | স্টেট                                                        |
| Rebuild | রি-বিল্ড                                                    |
| Declarative | ডিক্লারেটিভ                                             |
| Framework | ফ্রেমওয়ার্ক                                              |
| Callback | কলব্যাক                                                     |
| Named Argument | নেমড আর্গুমেন্ট                                      |
| Layout | লেআউট                                                        |
| Event | ইভেন্ট                                                        |
| Rendering | রেন্ডারিং                                                  |
| Escape Sequence | এস্কেপ সিকোয়েন্স                                    |
| Overflow | ওভারফ্লো                                                    |
| Hot Reload | হট রিলোড                                                 |
| Test Harness | টেস্ট হার্নেস                                           |
| Golden Test | গোল্ডেন টেস্ট                                            |
| Matrix | ম্যাট্রিক্স                                                    |
| Geometry | জ্যামিতি                                                     |
| Statistics | পরিসংখ্যান                                                 |
| Sort | সাজাও                                                          |
| Manifest | ম্যানিফেস্ট                                                 |
| Lock file | লক ফাইল                                                   |
| Dependency | নির্ভরতা                                                   |
| Commit (git) | কমিট                                                    |
