# কলম দিয়ে শুরু (Getting Started)

**সংস্করণ:** ১.০.০

এই ডকুমেন্ট কলম ইনস্টল করা থেকে শুরু করে প্রথম প্রোগ্রাম চালানো ও নেটিভ এক্সিকিউটেবল তৈরি করা পর্যন্ত পুরো পথ দেখায়।

ভাষার সম্পূর্ণ বর্ণনার জন্য দেখুন [`language.md`](language.md), আর ধাপে ধাপে শেখার জন্য [`tutorial.md`](tutorial.md)।

---

## ১. কলম কী

কলম একটি **বাংলা প্রোগ্রামিং ভাষা** — কীওয়ার্ড, টাইপ, ত্রুটি-বার্তা সবই বাংলায়। এটি অনূদিত কোনো ভাষা নয়; শুরু থেকেই বাংলাভাষীদের জন্য ডিজাইন করা।

```kolom
অ্যাপ {
    লেখো("হ্যালো বিশ্ব")
}
```

কলম দুইভাবে প্রোগ্রাম চালাতে পারে —

| উপায় | কমান্ড | কখন |
|-------|--------|------|
| **ইন্টারপ্রিটেড** | `কলম চালাও` | শেখার সময়, দ্রুত পরীক্ষা করতে |
| **নেটিভ কম্পাইল** | `কলম বিল্ড` | চূড়ান্ত বাইনারি তৈরি করতে (Windows ও Linux) |

## ২. ইনস্টল

### ২.১ ডাউনলোড ও PATH

১. কলম-এর zip ডাউনলোড করে যেকোনো ফোল্ডারে খুলুন, যেমন `C:\kolom`।

ফোল্ডারের গঠন —

```text
C:\kolom\
  kolom.exe
  sysroot\          ← এটি মুছবেন না; বিল্ডের জন্য দরকার
```

২. `C:\kolom` ফোল্ডারটি PATH-এ যোগ করুন, যাতে যেকোনো জায়গা থেকে `kolom` লেখা যায়।

**PowerShell (স্থায়ীভাবে, শুধু আপনার ইউজারের জন্য):**

```powershell
$new = [Environment]::GetEnvironmentVariable("Path","User") + ";C:\kolom"
[Environment]::SetEnvironmentVariable("Path", $new, "User")
```

এরপর টার্মিনাল বন্ধ করে নতুন করে খুলুন।

### ২.২ ইনস্টল যাচাই

```console
kolom সংস্করণ
```

আউটপুট —

```text
কলম ১.০.০
```

এটি দেখা গেলে ইনস্টল সম্পূর্ণ। **আলাদা করে কোনো C কম্পাইলার, Visual Studio, বা Rust ইনস্টল করার দরকার নেই** — কলম নিজের কম্পাইলার ও লিংকার নিজেই বহন করে।

## ৩. প্রথম প্রোগ্রাম

### ৩.১ নতুন প্রকল্প তৈরি

```console
kolom নতুন হ্যালো
```

এটি তৈরি করে —

```text
হ্যালো\
  main.ক
```

`main.ক`-এর ভেতরে —

```kolom
অ্যাপ হ্যালো {

    লেখো("হ্যালো, হ্যালো!")

}
```

> **নোট:** কলম ফাইলের এক্সটেনশন `.ক`, আর ফাইল UTF-8 এনকোডিংয়ে সংরক্ষণ করতে হয়। বেশিরভাগ এডিটর ডিফল্টভাবেই UTF-8 ব্যবহার করে।

### ৩.২ চালানো

```console
kolom চালাও হ্যালো/main.ক
```

```text
হ্যালো, হ্যালো!
```

### ৩.৩ নেটিভ এক্সিকিউটেবল তৈরি

```console
kolom বিল্ড হ্যালো/main.ক
```

কমান্ডটি তৈরি হওয়া `.exe`-র পুরো পথ ছাপে। সেটি চালালেই প্রোগ্রাম চলবে — কলম ইনস্টল না থাকা মেশিনেও।

### ৩.৪ Linux-এর জন্য বিল্ড (ক্রস-কম্পাইল)

Windows-এ বসেই Linux-এর জন্য প্রোগ্রাম তৈরি করা যায় —

```console
kolom বিল্ড হ্যালো/main.ক linux
```

ফলাফল একটি **সম্পূর্ণ স্ট্যাটিক** Linux বাইনারি — কোনো `.so` নির্ভরতা নেই, তাই যেকোনো ডিস্ট্রিবিউশনে (Ubuntu, Fedora, Alpine, Arch) সরাসরি চলে।

```console
$ ./main
হ্যালো, হ্যালো!
```

> **নোট:** Linux টার্গেটে UI (`ডিসপ্লে`, `বাটন`) এখনো কনসোল মোডে চলে — জানালা খোলে না। কনসোল প্রোগ্রাম সম্পূর্ণভাবে কাজ করে।

## ৪. ভাষার মৌলিক অংশ

### ৪.১ ভ্যারিয়েবল ও ধ্রুবক

```kolom
অ্যাপ {
    ধরি নাম = "রহিম"
    ধরি বয়স = ২৫
    ধরি উচ্চতা: দশমিক = ৫.৬

    লেখো(নাম)
    লেখো(লেখায়(বয়স))
}
```

- `ধরি` — ভ্যারিয়েবল (পরে বদলানো যায়)
- `ধ্রুবক` — ধ্রুবক (বদলানো যায় না)
- টাইপ সাধারণত লিখতে হয় না, কলম নিজেই বুঝে নেয়
- বাংলা (`২৫`) ও ইংরেজি (`25`) — দুই ধরনের সংখ্যাই লেখা যায়

### ৪.২ টাইপ

| টাইপ | অর্থ | উদাহরণ |
|------|------|---------|
| `সংখ্যা` | পূর্ণসংখ্যা | `২৫` |
| `দশমিক` | দশমিক সংখ্যা | `৩.১৪` |
| `লেখা` | টেক্সট | `"কলম"` |
| `বুলিয়ান` | সত্য/মিথ্যা | `সত্য` |
| `অক্ষর` | একটি অক্ষর | `'ক'` |
| `ফাঁকা` | কোনো মান নেই | |

### ৪.৩ শর্ত ও লুপ

```kolom
অ্যাপ {
    ধরি বয়স = ২০

    যদি (বয়স >= ১৮) {
        লেখো("প্রাপ্তবয়স্ক")
    } নাহলে {
        লেখো("অপ্রাপ্তবয়স্ক")
    }

    ধরি গণনা = ০
    যতক্ষণ (গণনা < ৩) {
        লেখো(লেখায়(গণনা))
        গণনা = গণনা + ১
    }
}
```

`বিরতি` দিয়ে লুপ থামানো যায়, `চলবে` দিয়ে পরের ধাপে যাওয়া যায়।

### ৪.৪ ফাংশন

```kolom
ফাংশন যোগ(সংখ্যা ক, সংখ্যা খ) -> সংখ্যা {
    রিটার্ন ক + খ
}

অ্যাপ {
    লেখো(লেখায়(যোগ(১০, ২০)))
}
```

ফাংশনের প্যারামিটার ও রিটার্ন টাইপ স্পষ্ট করে লিখতে হয়।

### ৪.৫ অ্যারে ও ম্যাপ

```kolom
অ্যাপ {
    ধরি নামসমূহ = ["রহিম", "করিম"]
    লেখো(লেখায়(দৈর্ঘ্য(নামসমূহ)))

    প্রতি (নাম : নামসমূহ) {
        লেখো(নাম)
    }

    ধরি বয়স: ম্যাপ[লেখা, সংখ্যা] = ম্যাপ_তৈরি()
    বয়স["রহিম"] = ২৫
    লেখো(লেখায়(বয়স["রহিম"]))
}
```

## ৫. স্ট্যান্ডার্ড লাইব্রেরি

মডিউল ব্যবহারের আগে `ইম্পোর্ট` করতে হয় —

```kolom
ইম্পোর্ট গণিত
ইম্পোর্ট লেখা

অ্যাপ {
    লেখো(লেখায়(গণিত.বর্গমূল(১৬.০)))
    লেখো(লেখা.বড়হাতের("kolom"))
}
```

| মডিউল | কাজ |
|-------|-----|
| `গণিত` | বর্গমূল, ঘাত, সাইন, রাউন্ডঅফ, সর্বনিম্ন, সর্বোচ্চ … |
| `লেখা` | ছাঁটো, স্প্লিট, জুড়াও, স্লাইস, খুঁজো … |
| `ফাইল` | পড়ো, লেখো, এপেন্ড, লাইন_তালিকা |
| `ফাইলসিস্টেম` | ডিরেক্টরি ও ফাইল ব্যবস্থাপনা |
| `পাথ` | পাথ ম্যানিপুলেশন (জোড়ো, ফাইলনাম, এক্সটেনশন …) |
| `জেসন` | JSON পড়া ও লেখা |
| `সময়` | সময় ও সেকেন্ড |
| `র‍্যান্ডম` | এলোমেলো সংখ্যা |
| `নেটওয়ার্ক` | TCP সংযোগ |
| `গ্রাফিক্স` | ক্যানভাসে আঁকা |

কিছু ফাংশন ইম্পোর্ট ছাড়াই সবসময় পাওয়া যায় — `লেখো`, `দৈর্ঘ্য`, `লেখায়`, `কপি`, `পড়ো_লাইন` ইত্যাদি।

উদাহরণ —

```kolom
ইম্পোর্ট ফাইল

অ্যাপ {
    ফাইল.লেখো("তথ্য.txt", "শুভ দিন")
    লেখো(ফাইল.পড়ো("তথ্য.txt"))
}
```

## ৬. একটি জানালা (UI) খোলা

কলম-এ নেটিভ UI ভাষার অংশ — আলাদা লাইব্রেরি লাগে না।

```kolom
ফাংশন চাপা_হলো() -> ফাঁকা {
    লেখো("বাটন চাপা হয়েছে")
}

অ্যাপ গণক {
    ডিসপ্লে {
        টেক্সট("স্বাগতম")
        সারি() {
            বাটন("চাপুন", চাপা_হলো)
        }
        ইনপুট()
    }
}
```

`কলম বিল্ড` করলে এটি একটি সত্যিকারের উইন্ডো খোলে।

## ৭. সমস্যা সমাধান

**`kolom` কমান্ড পাওয়া যাচ্ছে না**
PATH ঠিকভাবে সেট হয়নি, বা টার্মিনাল পুনরায় খোলা হয়নি। §২.১ দেখুন।

**`কলম রানটাইম পাওয়া যায়নি` / `MinGW-w64 লাইব্রেরি পাওয়া যায়নি`**
`sysroot` ফোল্ডারটি `kolom.exe`-র পাশে নেই। zip-টি সম্পূর্ণভাবে খুলুন। অন্য জায়গায় রাখতে চাইলে —

```powershell
$env:KOLOM_SYSROOT = "D:\যেখানে\sysroot"
```

**বাংলা লেখা টার্মিনালে ভাঙা দেখাচ্ছে**
দুটি আলাদা কারণ হতে পারে —

১. **মোজিবেক (উল্টাপাল্টা বাইট/বাক্স)** — টার্মিনাল UTF-8 বুঝছে না।

```powershell
chcp 65001
```

Windows Terminal ব্যবহার করলে সাধারণত এই সমস্যা হয় না।

২. **যুক্তাক্ষর/মাত্রা বিচ্ছিন্ন দেখাচ্ছে** (অক্ষর ঠিক আছে, কিন্তু ক্ষ, জ্ঞ ইত্যাদি জোড়া না লেগে আলাদা দেখাচ্ছে) — এটা এনকোডিং সমস্যা নয়, টার্মিনালের রেন্ডারার জটিল স্ক্রিপ্ট শেপিং করতে পারছে না। এই রিপোর সাথে `.vscode/settings.json`-এ এর সমাধান আগে থেকেই দেওয়া আছে (VS Code-এ রিপো খুললে স্বয়ংক্রিয়ভাবে কার্যকর হয়) —

```json
"terminal.integrated.gpuAcceleration": "off",
"terminal.integrated.fontFamily": "Cascadia Code, 'Nirmala UI', monospace"
```

VS Code ছাড়া অন্য টার্মিনালে (যেমন স্বতন্ত্র Windows Terminal) এই সেটিংস নিজে যোগ করতে হবে, অথবা ফন্ট সেটিংয়ে `Nirmala UI` ফলব্যাক হিসেবে যোগ করুন।

**ফাইল সেভ করার পর কোড চিনছে না**
ফাইলটি UTF-8-এ সংরক্ষিত কি না দেখুন, আর এক্সটেনশন `.ক` কি না যাচাই করুন।

**কলম দিয়ে তৈরি করা প্রোগ্রামের উপর কোনো লাইসেন্স-বাধ্যবাধকতা নেই।** আপনার লেখা প্রোগ্রাম আপনি যেভাবে খুশি লাইসেন্স করতে ও বিতরণ করতে পারেন — ক্লোজড সোর্স হিসেবেও।

বিতরণে অন্তর্ভুক্ত তৃতীয় পক্ষের উপাদানের (rust-lld, MinGW-w64) নোটিশ `THIRD-PARTY-NOTICES.md`-এ আছে।

---

### ডেভেলপারদের জন্য: সোর্স থেকে বিল্ড

```console
git clone <repo> && cd Kolom
rustup target add x86_64-pc-windows-gnu
bash scripts/make-sysroot.sh dist release
```

`dist/` ফোল্ডারে সম্পূর্ণ, বিতরণযোগ্য কলম তৈরি হবে।
